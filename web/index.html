INTERACTIVE EXPERIMENTS

在瀏覽器直接測試

點擊測試按鈕，觀察真實的 HTTP 回應。
所有請求都使用同源路徑，不需要 CORS 設定。

01 / NETWORK↗

Reverse Proxy

透過 Nginx 存取主 API，確認實際到達哪個後端以及轉發的 Headers。

GET /api/info

按下按鈕查看 HTTP 回應。

02 / DISTRIBUTION⇄

Load Balancing

連續發送 8 次請求，觀察 Round Robin 將流量分配給兩個 API Instance。

GET /lab/balance

每次回應的 instance 會列在這裡。

03 / TRAFFIC CONTROL≋

Rate Limiting

快速送出 12 次請求，比較允許通過的 200 和超額拒絕的 429。

GET /lab/rate

限制設定：2 req/s，burst=3，nodelay。

04 / RESILIENCE◷

Proxy Timeout

比較後端延遲 2 秒與 5 秒的回應，觀察 Nginx 設定的 3 秒讀取逾時。

GET /lab/timeout?seconds=2|5

正常情況：2 秒回傳 200，5 秒約 3 秒後回傳 504。

05 / PERFORMANCE⇣

Gzip Compression

請求大型文字檔並檢查 Content-Encoding。瀏覽器會自動解壓縮回應內容。

GET /lab/gzip/large.txt

重點觀察 Content-Encoding 與 Vary。

06 / PERFORMANCE◫

Browser Cache

以同一網址請求 CSS 兩次，觀察 max-age、Expires 與瀏覽器的資源計時資訊。

GET /lab/cache/cache.css

測試使用同一個新網址，第二次可由快取提供。

07 / ERROR HANDLING!

Custom Error Page & Static Files

請求不存在的資源，驗證自訂 404 頁仍保留 HTTP 404 狀態；也可以直接造訪 Nginx 提供的靜態文件。

GET /__nginx_lab_missing_resource
開啟靜態文件 ↗

自訂錯誤頁不應把 HTTP 404 改成 200。
